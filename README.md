# Travel Sponsor Pack Automation (V2)

**Author:** Webster Williams  
**Technical Assistance:** ChatGPT (OpenAI)  
**License:** MIT  

This VBA Macro Suite automates the creation of professional sponsor presentation packs for the *Travel Secure Audio Link* project.  
It dynamically formats documents, inserts sponsor info, and exports both DOCX and PDF versions automatically.

---

### Usage
1. Open Microsoft Word → Press `Alt + F11`.
2. Import `Build_Travel_Sponsor_Pack_V2.bas` into a module.
3. Run `Build_Travel_Sponsor_Pack_V2`.

---

### Output
- Automatically saves files to:  
  `~/Documents/Travel/ip-build/`
- Generates:  
  - `Travel-Sponsor-EmailPack_<timestamp>.docx`  
  - `Travel-Sponsor-EmailPack_<timestamp>.pdf`
